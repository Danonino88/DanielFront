# Vistas de Alumno (`/src/views/student`)

### Reglas básicas:
1. **Acceso público/alumno**: Vistas de solo lectura para consulta de la oferta universitaria.
2. **Funcionalidades permitidas**:
   - Visualizar las carreras que están en estado **Publicada**.
   - Descargar o ver planes de estudio.
3. **Restricción**: Ningún componente de esta carpeta debe tener botones de edición o creación de datos.
